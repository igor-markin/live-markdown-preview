Features

Everything a Markdown draft needs. Nothing it doesn't.

  • Instant preview

    Rendering runs in a Web Worker, so even long documents do not freeze the editor.

  • GitHub Flavored Markdown

    Tables, task lists, strikethrough, autolinks and raw HTML — the way GitHub shows them.

  • Many drafts, one place

    A file sidebar, an outline of headings and a resizable split. Open and download real .md files.

  • Clean HTML in one click

    Copy Markdown or sanitized HTML, ready to paste into a CMS, an email or a docs page.

  • Print and PDF

    The preview prints cleanly: use the browser's Save as PDF to share a finished page.

  • Hard to lose work

    Autosave, a conflict warning when two tabs edit one draft, and recovery of unsaved edits after a reload.

Privacy

Your words never leave this browser.

  1. 1

    You type

    CodeMirror edits the source. The page is static files, with no backend to send anything to.

  2. 2

    A worker renders

    unified and remark turn Markdown into HTML in a background thread.

  3. 3

    DOMPurify cleans

    Scripts, event handlers, frames, forms and unsafe links are removed before anything is shown.

  4. 4

    IndexedDB keeps

    Drafts and preferences are saved locally on this device. No analytics, no telemetry.

Local means local: drafts live only in the browser and on the address where you wrote them. Clearing site data deletes them, so download important files as .md.
